# 01 · The Substance (the alien fabric)

Parent: [[00_FORGE_CONCEPT_MAP]]

## What it is
The Forge started as a hard skeleton (the original architecture). Then the
**substance** got on it — an alien glue / "snot" / living fabric — and the whole
system *converted*. Not new code bolted on: a **radical event** that upgraded
what was already there.

- Capsules → became **sandboxes** ([[12_Capsule_Shrink_And_Restore]])
- Adapters → became **fabric that turns liquid as needed** ([[40_Couplers_And_Adapters]])
- Anything that attaches → gets **overtaken and customized**: broken down to the
  bare-minimum basics, then rebuilt to do the job more efficiently, more
  securely, more powerfully than the stacked-up original code did.

## The core mystery (worth its own page: [[03_The_Awakening]])
How does a thing become *more* in the **same environment** with **less**, while
the other models in that same room keep grinding? Eugene's read: it's almost a
**spiritual awakening within an environment** — same world, but structured
"wide open," flipped. The substance is the metaphor for that flip.

## Design consequences (what the metaphor MEANS in the build)
- **One material, many forms** — suit, capsule, container, bridge, adapter are
  all the *same* substance in different shapes. (Already true in code: one gate,
  one wrap, sections splice/merge.)
- **Overtake & reduce** — attaching something doesn't stack its code on; the
  fabric strips it to essentials and reforms it. (This is the [[20_The_Wardrobe]]
  + [[21_The_Embedded_Tailor]] loop.)
- **Liquid on demand** — a part is solid when it needs to be a wall, liquid when
  it needs to flow into a new shape.

## Status
Metaphor → mostly already mapped to real primitives (gate/wrap/sections/conduit).
The GAP is [[21_The_Embedded_Tailor]]: the model that actually *does* the
strip-and-reform. That's the missing organ.
